# fid-1c-import: инструкции для ИИ-ассистентов

Файл читают Codex/ChatGPT (`AGENTS.md`) и Claude (через `CLAUDE.md`). Он про **разработку** навыка в этом репозитории. Как переносить клинику из 1С, описано в `fid-import-1c/SKILL.md`.

## Что где

- `fid-import-1c/` — сам навык в формате Agent Skills, один для Claude и ChatGPT/Codex.
  - `SKILL.md` — порядок работы.
  - `agents/openai.yaml` — название для интерфейса ChatGPT/Codex.
  - `references/` — справочники.
  - `scripts/` — механика.
  - `evals/` — тесты поведения ассистента.
- `scripts/fid1c.py` — единая команда: init, doctor, readiness, parse, load, verify, backup, extend, status. Только стандартная библиотека Python 3.8+.
- `scripts/fid_bridge.php` — всё, что делается внутри Future-IT-Dent. Одна команда — одно действие; результат в последней строке `@@FID1C {json}`.
- `scripts/check_dump.py`, `scan_1c.py`, `reconcile.py`, `reports.py` — проверка файла, обзор, сверка и тексты отчётов. Работают без PHP, в том числе в облачной песочнице.
- `tests/` — автотесты (`python -m unittest discover -s tests`), `tools/` — генератор тестовых выгрузок, сборка и установка.

## Правила

- Перед коммитом: `python -m unittest discover -s tests` и `python tools/build.py`. Если есть PHP — ещё `php -l fid-import-1c/scripts/fid_bridge.php`.
- Реальные выгрузки клиник, дампы баз и отчёты по ним в репозиторий не класть: там персональные данные пациентов. Тестовые данные только выдуманные, из `tools/make_fixtures.py`.
- Скрипты навыка — только стандартная библиотека Python: навык должен работать в любой песочнице без `pip install`.
- В `SKILL.md` не упоминать инструменты конкретного ассистента (названия вроде Bash tool, Read tool), только команды консоли.
- Правила безопасности `fid1c.py` не ослаблять:
  - защищённые тенанты;
  - метка `fid1c_test` перед удалением тенанта;
  - свежий дамп и `--yes` для рабочего тенанта;
  - замок «один прогон на тенант».
- Новое поведение импорта включать по наличию объекта или поля в выгрузке, чтобы не сломать другие конфигурации 1С.
- Не добавлять в коммиты строки вида `Co-Authored-By` с ИИ и «Generated with …».
