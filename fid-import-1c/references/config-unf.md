# 1С:Медицина на базе УНФ

Узнаётся по `CatalogObject.Контрагенты` + `CatalogObject.СтруктурныеЕдиницы` + документам `Событие`, `Прием`, `ПоступлениеДенежныхСредств`. Пример: ДЕНТАЛ АСК (Челябинск), 2,4 ГБ, 525 пациентов, 803 записи, 435 счетов.

| Что | Где в 1С | Куда в FID | Особенности |
| --- | --- | --- | --- |
| Филиал | `СтруктурныеЕдиницы` (+ `ЧасовойПояс`) | `branches` | `Филиалы` нет; пояс переносится в `branches.time_zone` |
| Пациенты | `Контрагенты` с `ТипКонтрагента = Клиенты` | `users`, `personal_users`, `patients` | там же поставщики и лаборатории; помеченные на удаление не переносятся |
| Телефоны, email | табличная часть `КонтактнаяИнформация` в карточке | `personal_users.phone`, `users.email` | `Тип`: Телефон / Адрес / АдресЭлектроннойПочты / СоциальнаяСеть |
| Медкарты | `МедицинскиеКарты.КодБезНулей`, `ВладелецКарты` | `personal_users.cart` | |
| Паспорта | регистр `ДокументыФизическихЛиц` | `personal_users.passport_*` | у детей там свидетельство о рождении (`ЯвляетсяДокументомУдостоверяющимЛичность = false`) |
| Иждивенцы | дети только с непаспортными документами | `family`, `family_user` | законный представитель в 1С обычно пуст; опекун — взрослый пациент с тем же телефоном |
| Сотрудники | `Сотрудники` + `Должности` | `doctors` / `employees` | уволенные = `DeletionMark`, переносятся неактивными |
| Услуги | `Номенклатура` с `ЭтоУслуга = true` | `services` | остальное — материалы и запасы |
| Цены | регистр `ЦеныНоменклатуры`, вид цен = `СтруктурныеЕдиницы.ВидЦенРеализации` | `services.price` | второй вид цен — закупочный, не брать |
| Записи | `Событие` (проведённые): `Контрагент`, `Услуги.Сотрудник`, `Услуги.ДатаНачала/Окончания`, `Статус` | `appointments` | `Услуги.Помещение` = кабинет, заполнен не у всех |
| Счета | `Прием` (проведённые): `Лечение` + `Запасы` (проданные товары) | `invoice`, `services_treatment_plan` | `СуммаДокумента` = Σ `Лечение.Сумма` + Σ `Запасы.Сумма` |
| Оплаты | `ПоступлениеДенежныхСредств`: `РасшифровкаПлатежа.ДокументОснования` → `Прием` | `money_operations` | без счёта → предоплата; `ПоступлениеРозничнойВыручкиИзОперационнойКассы` — инкассация, не оплата |

Статусы `Событие` → визит: ПриемОкончен 7, ПриемНачат 1, ПациентОжидает 2, Подтверждена 6, Запланировано 5, ПриемОтменен / ПриемНеСостоялся / НеПодтверждена 4 (запись неактивна).

Нормальные расхождения сверки: оплата из «Взноса на лицевой счёт» лежит предоплатой, а в 1С закрывает счёт; счёт «в долг» (`Долговой = true`) в 1С показан неоплаченным.
