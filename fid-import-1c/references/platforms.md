# Где работает навык

Навык сделан по открытому формату Agent Skills: папка с `SKILL.md`, `scripts/` и `references/`. Одна и та же папка подключается к Claude и к ChatGPT/Codex. Вся механика живёт в `scripts/fid1c.py`, поэтому результат не зависит от того, какой ассистент её запускает.

| Где | Как подключить | Что доступно |
| --- | --- | --- |
| Claude Code (терминал, десктоп-приложение, IDE) | `python tools/install.py --claude` → `~/.claude/skills/fid-import-1c` | всё: проверка, загрузка, сверка |
| Claude.ai (веб, мобильное приложение) | Настройки → Возможности → Навыки → загрузить `dist/fid-import-1c.zip` | шаг 1 по загруженному файлу и сверка по присланным выгрузкам; загрузки в FID нет (нет доступа к компьютеру) |
| ChatGPT, десктоп-приложение | `python tools/install.py --agents` → `~/.agents/skills/fid-import-1c`; либо раздел Skills → загрузить папку или zip | всё, если приложению разрешено запускать команды на компьютере |
| Codex (CLI, IDE) | то же `~/.agents/skills` или папка `.agents/skills` в репозитории; вызов `$fid-import-1c` или по описанию | всё |
| ChatGPT в браузере | отдельные навыки там недоступны: только навыки в составе плагинов | — |
| Без ИИ | `python fid-import-1c/scripts/fid1c.py …` из консоли | всё; раздел «Комментарий» в отчётах пишет человек |

## Ограничения облачных чатов

- В облачную песочницу (Claude.ai, ChatGPT) обычно нельзя загрузить файл в несколько гигабайт. Шаг 1 по большой выгрузке делай локально.
- В песочнице нет PHP, MySQL и Future-IT-Dent: команды `doctor`, `load`, `verify --tenant/--db`, `backup` там не работают. Работают `readiness --no-fid` и `verify --export`.
- Чтобы сверить базу из облачного чата, загрузи туда две папки: `work/V8Exch_Data` и выгрузку базы (`work/audit_<id>`), затем запусти `python scripts/fid1c.py verify --work <папка с V8Exch_Data> --export <папка выгрузки базы>`.

## Чем отличаются платформы для автора навыка

- Описание из `SKILL.md` ChatGPT/Codex показывает вместе со списком всех навыков и может его сократить. Поэтому главное — в первых двух предложениях.
- `agents/openai.yaml` — название и подсказка для интерфейса ChatGPT/Codex. Claude его не читает.
- Названия инструментов ассистента (Bash, PowerShell, shell) в навыке не упоминаются: только команды консоли, которые одинаковы везде.
