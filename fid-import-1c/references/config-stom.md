# 1С:Стоматологическая клиника

Узнаётся по `CatalogObject.Клиенты` + `DocumentObject.Заявка` + `DocumentObject.ОказаниеУслуг`. Константы `Б24_…`, `бит_сл_…`. Пример: СЕРКИН.СТОМ, «Моцарт» (Ижевск), 5 253 пациента, 2 472 заявки, 1 762 счёта.

| Что | Где в 1С | Куда в FID | Особенности |
| --- | --- | --- | --- |
| Филиал | `Филиалы` | `branches` | часового пояса нет — узнать у клиники или по серии паспортов (первые 2 цифры = регион) |
| Организация | `Организации` (ИНН, КПП, ОГРН) | `legal_entities` | адреса, банк, лицензия — в регистрах |
| Пациенты | `Клиенты` | `users`, `personal_users`, `patients` | `Контрагенты` тут — организации, не пациенты; среди клиентов бывают служебные записи («Генеральная уборка», «Стрижка») для блокировки времени |
| Телефоны, email | регистр `КонтактнаяИнформация` | | в карточке клиента их нет |
| Медкарты | `МедицинскиеКарты.НомерКарты`, `Клиент` | `personal_users.cart` | |
| Паспорта | регистр документов; запасной источник — `СправкаДляНалоговой` (`СерияДУЛ`, `НомерДУЛ`, `ВидДУЛ = 21`) | `personal_users.passport_*` | только где `ПациентЯвляетсяНалогоплательщиком = true` |
| Сотрудники | `Сотрудники` + `Должности` | `doctors` / `employees` | у многих врачей должность пустая — врач тот, кто `УчаствуетВКалендарномПланировании` или есть в заявках/оказаниях; есть колонки-ресурсы («Диагностика 1», группа «Рентген») |
| Услуги | `Номенклатура` с `ВидНоменклатуры = Услуга` | `services` | |
| Цены | регистр `ЦеныНоменклатуры` | `services.price` | без регистра — самая частая цена продаж дороже 1 ₽ из `ОказаниеУслуг.Работы.Цена` |
| Записи | `Заявка`: `Клиент`, `Сотрудник`, `ДатаНачала`, `ДатаОкончания`, `Состояние` → `ВидыСостоянийЗаявок` | `appointments` | заявки не проводятся (`Posted = false` у всех); `Событие` здесь — звонки; кабинетов нет |
| Счета | `ОказаниеУслуг` (проведённые, `ПродажаКлиенту`): `Работы` + `Товары` | `invoice` | `Прием` — протокол осмотра с HTML, без цен; его JSON часто битый |
| Оплаты | `ОказаниеУслуг.Оплата` (`ВидОплаты`: Безналичные / Наличными) + `ПриходныйКассовыйОрдер` + `ОплатаПлатежнойКартой` | `money_operations` | ПКО с «Начисление ДМС» — аванс ДМС на лицевой счёт, безнал |
| Возвраты | `ОказаниеУслуг` с `ВидОперации = ВозвратКлиенту`, `ДокументОснование` → счёт | `money_operations` (rollback) | |

Состояния заявок → визит: Выполнена 7, Проведен прием (`Прием`) 7, Запланирована 5, Отменена 4 (неактивна).

Кресла: в 1С журнал по сотрудникам, кабинетов нет — `chairs_by_appointments.php` раскладывает записи по креслам тенанта без наложений; остаток пересечений = моменты, когда записей больше, чем кресел.
