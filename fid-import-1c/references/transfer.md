# Перенос в рабочий тенант

Только после того, как тестовый прогон сошёлся с 1С, и только по явному «да» пользователя в этом разговоре.

1. **Что в тенанте сейчас.** `python fid1c.py doctor` показывает тенанты. Если в рабочем тенанте данные другой клиники или уже залитый импорт, спроси пользователя, очистить ли его (откат из дампа «до импорта»). Поверх загруженного не заливать: `load --production` сам откажет, если там уже есть пациенты, счета или услуги из 1С.
2. **Дамп.** `python fid1c.py backup --tenant <id>` → `backups/tenant<id>_<время>.sql`. Скрипт проверяет, что дамп закончен (`Dump completed`). Откат: `mysql tenant<id> < backups/…sql`.
3. **Часовой пояс.** Для Стоматологической клиники заранее задай `"timezone"` в `fid1c.json`: пояс ставится сразу после загрузки филиала, до записей.
4. **Загрузка.** `python fid1c.py load --tenant <id> --production --backup backups/<дамп>.sql --yes`. Что делает команда:
   - тенант не пересоздаётся;
   - дамп должен быть не старше 3 часов;
   - почта, рассылки и внешние запросы выключены;
   - после загрузки записи раскладываются по креслам и сразу идёт сверка.
5. **Остановка посередине.** Если прогон остановился между шагами, продолжить можно командой `load … --production --backup … --yes --resume`. Если шаг прерван внутри (часть строк загружена), продолжать нельзя: откат из дампа и заново.
6. **Подписка.** Если `date_end` в прошлом, команда предупредит. Продление: `python fid1c.py extend --tenant <id> --date ГГГГ-ММ-ДД`, только по согласию пользователя.
7. **Карточка предприятия** (`legal_entities`): реквизиты из 1С (`Организации`) или от клиники. Заполняется в программе или запросом, по согласию пользователя.
8. **Итог** — `reports/final_<id>.md`: показать пользователю и объяснить расхождения.

## Сервер

`fid1c.py` рассчитан на локальный Future-IT-Dent. На сервере тот же порядок:
1. Загрузить и проверить локально.
2. Перенести базу тенанта дампом: `backup`, затем импорт дампа на сервере по регламенту компании.

Дамп с сервера на проверку: поднять в отдельную локальную базу (`CREATE DATABASE chk; mysql chk < dump.sql`) и запустить `python fid1c.py verify --db chk`.
