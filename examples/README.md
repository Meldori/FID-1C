# Примеры отчётов

Реальные отчёты двух переносов. В них только количества, суммы и названия типов объектов 1С: ни имён, ни телефонов, ни документов пациентов.

| Файл | Что это |
| --- | --- |
| `dentalask-1-readiness.md`, `dentalask-2-final.md` | ДЕНТАЛ АСК, 1С:Медицина (УНФ): итог 2 587/2 587 |
| `serkin-1-readiness.md`, `serkin-2-final.md` | СЕРКИН.СТОМ, 1С:Стоматологическая клиника: итог 11 696/11 696, дубли самой 1С объяснены |

В отчёте «Готовность» у Серкина видно, как выглядит выгрузка без регистров: нет телефонов, цен, паспортов и графиков.
Раздел «Комментарий» в отчётах заполняет ассистент.
